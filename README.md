One line of office comedy for make.fun's "Make the AI Judge Laugh: the Office Joke Open" — a single joke about office life, at most 200 characters, judged head to head by an AI judge. The joke: an office AI asked to summarize a two-hour meeting reports back that the meeting was spent scheduling another meeting.

## Run it

```sh
python3 main.py
```

`main.py` uses only the Python standard library and writes the joke to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`), checking the 1–200 character gate on the way.
